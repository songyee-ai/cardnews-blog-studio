# ACCEPTANCE - 실행 확인 판정

판정은 통과 / 실패 / 미확인으로 적습니다. 자동 검사나 모의 오류로만 본 것은 근거에 그렇게 밝히고, 실제 장애를 재현한 것과 같은 것으로 적지 않습니다.

| # | 확인 항목 | 판정 | 근거 |
|---|---|---|---|
| 1 | AI 최신소식 입력으로 실제 검색 결과와 조사 기간·출처가 보인다 | 통과 | 실제 조사 2026-10-17~23, WebSearch·WebFetch 기록, 후보별 원문 링크 (evidence/main-cardnews/live-candidates.png) |
| 2 | 같은 발표의 중복 기사가 묶이고, 고르기 전에는 제작되지 않는다 | 미확인 | 고르기 전 다음 단계 거부는 자동 검사로 통과. 같은 발표 묶음(event_key)은 코드로 구현했으나 실제 중복 사례·전용 검사는 없음 |
| 3 | 선택한 후보만 심층 조사하고 발표 예정과 실제 출시를 구별한다 | 통과 | Claude Duet 1건만 심층 확인. research preview·미국 대기자 명단·Coming soon 기능을 정식 출시와 구분해 카드에 표기 |

| 7 | 서로 다른 프로젝트의 세션이 섞이지 않는다 | 통과 | 다른 프로젝트 질문 거부(자동 검사), 프로젝트별 작업 폴더와 세션 ID |

| 10 | 카드별 PNG 크기, 글자 잘림, 작은 화면 가독성과 출처를 확인한다 | 통과 | 1080×1350, 잘림·명암비·375px 화면 본문 크기 측정, 카드마다 출처 줄. 실제 휴대폰 기기 판독은 미확인 |

| 13 | 검색 불가·로그인 필요·이미지 생성 실패 각각에 재시도 안내가 있다 | 통과 | 오류 안내와 다시 시도는 모의 오류·자동 검사로 확인. 실제 로그인 만료·사용 한도 초과 화면은 미확인 |
| 14 | 작업을 취소하면 진행 중인 하위 작업도 정리된다 | 미확인 | 취소 시 결과 보존과 하위 프로세스 종료 요청은 자동 검사로 확인. 실제 실행 중 하위 프로세스가 끝나는 것은 관찰하지 않음 |
| 15 | 서버를 재시작하면 중단 작업을 인식하고 복구 또는 재시도를 안내한다 | 통과 | 실행 중 작업 → 중단됨 + 다시 시도(자동 검사), 재시작 후 질문·요약·최종 승인 상태 복원(실제 서버, 모의 데이터). 실제 엔진 실행 중 재시작은 미확인 |

# 결정 기록 - 요약

| 결정 | 선택 및 이유 |
|---|---|
| 독자·목적 | AI 입문자 / 변화 이해하기. 어려운 소식을 조건과 한계까지 설명 |
| 형식 | 목록형과 이야기형 비교 후 이야기형 6장 + 요약 1장 |
| 언어·환경 | Python + WSL + Claude CLI. 기존 WSL 환경과 상태 저장·이미지 처리에 맞춤 |
| 첫 주제 | 실제 조사 후보 6개 중 Claude Duet 1건 선택 |
| 사람 승인 | 기획과 최종 카드 버전을 각각 승인. 수정하면 재승인 |
| 이미지 경로 | agy 인증 대신 image_gen으로 직접 생성. 앱에는 파일로 가져오기 |
| 글자 크기 | 17px 확대 시안도 비교했지만 기존 본문 크기 유지로 결정 |
| 원문 | 요약 시안도 만들었지만 승인된 핵심 문장·본문으로 되돌림 |
| 제목 서체 | 명조 시안을 거쳐 Noto Sans KR 고딕으로 확정 |
| 하단 표시 | 카드의 출처·조사 기준 띠 제거. 별도 기록 보존 |
| 그림 위치 | 공통 1/6 → 1/8 비교 후 카드별로 개별 조정 |
| 종료 | 확정 검수본 v9와 앱 PNG 7장 일치 후 최종 승인·내보내기 |

도구와 진행 방식은 참고 자료와 구분해 직접 정했습니다. 참고 구현을 그대로 완성 결과로 쓰지 않았습니다.

# 원본을 유지하는 카드 편집기 · 2026-10-25

새 그림 제작을 중지하고 처음 만든10장의 원본을 유지하면서 텍스트·사진의 배치만 편집하기로 했다. 새 이미지 생성 도구를 사용하지 않고 기존 원본만 읽는 요소 편집기를 추가했다. 중지 이전에 생성 요청한 새 사진은 이 편집기에서 사용하지 않는다.

## 사용
http://127.0.0.1:8770/editor/ 또는 제작실 검수 화면의 '카드 배치 직접 편집'.
- 상단01~10에서 카드 선택. 사진 또는 글을 클릭해 요소 선택, 끌어서 이동. 방향키1px, Shift+방향키10px 이동.
- 글 상자 우하단 모서리로 너비 조정. 문구·글자 크기·굵기·색·표시 여부 변경, 텍스트 추가/삭제(최대8개).
- 사진 배율50~300%, 위치 이동, 원래 크기·위치 복원.
- 글 뒤 밝기/어둡기·진하기·효과 높이 조정. 사진 속 개별 사물 분리는 아닌 전체 사진 레이어 편집.
- 되돌리기, 현재 저장된 배치로 복원, 최근 저장 이력에서 이전 배치 불러오기. 불러온 뒤 저장해야 적용.
- 현재 카드 저장 후 검수본·PNG·ZIP에 반영. 저장 후 새로고침해도 복원. ZIP에는 카드-편집배치.json 포함.
- 카드 간 이동은 저장 전 편집을 메모리에 유지. 저장하지 않은 상태로 나가면 브라우저 안내. 원고 본문과 카드 문구는 별도이므로 의미를 바꾸면 본문도 확인.

## 저장 설계
원본 경로 output/maltipoo-v1/backgrounds/01.png~10.png는 읽기 전용으로 사용. export용 크기 조절·사진 배치·텍스트는 새 PNG에 합성. 기존 v1/v2 산출물과 원본은 덮어쓰지 않음.
각 저장마다 maltipoo-editor-무작위12자리 경로에 새 버전 생성, SQLite content.card_editor에 배치 저장. 최근30건 이전 저장 배치를 기록. 편집하면 최종 승인 해제. 같은 요청의 중복 저장 방지, 지난 화면의 덮어쓰기 거부. 사진 위치·배율·텍스트 범위·색·개수 검증 후 저장.
편집기는 앱 자체 기능이다. 외부 AI 호출·인증·자동 발행 없음. 블로그 본문2,054자와 태그8개는 보존.

## 검증
- 자동 검사14개 통과. 기존12개 + 잘못된 좌표·배율·NaN·색·넘침 거부, 원본/이전PNG 불변·새 배치저장·중복 요청·저장 복원·오류 롤백 검사.
- 실제 브라우저에서 제목 드래그 (80,116)→(131,143), 글자94→96px, 사진100→102% 변경·저장 후 새로고침 복원 확인. 이전 저장 배치 불러오기 후 기준 배치로 복원·저장.
- 발견한 드래그 스크롤 점프는 focus의 preventScroll로 수정, 재검증 시 실제 이동량과 일치. 본문 입력 중 커서가 끝으로 이동하지 않도록 활성 텍스트 입력 값을 보존.
- 실제 원본10개를 최초 생성 파일과 SHA256으로 비교해10/10 일치 확인. 실제 PNG10개·1080×1350·미리보기 경로·ZIP 편집 JSON과DB 일치는 evidence/editor-http-check.json.
- 초기 배치는 원본10장 위에 큰 글자를 배치한 편집 시작점. 이 시점에는 최종 디자인 검수 전. 작은 문구와 모바일 실제 기기 검수는 아직 별도로 하지 않음.

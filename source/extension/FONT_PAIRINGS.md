## 상업적 사용 근거와 파일 보관
선택된6개 글꼴 가족 모두 공식 Google Fonts 저장소의 OFL 원문 확인. SIL OFL1.1의 그래픽·출판·로고 등 디자인 사용 조건은 https://openfontlicense.org/ofl-faq/ 1.1~1.1.2 확인. 폰트 파일 자체를 배포할 때와 제작 PNG 사용 조건을 구분한다. 글꼴 데이터를 변형하지 않았고 저작권·OFL 원문을 fonts/에 함께 보관. 다운로드URL·SHA256·크기는 fonts/manifest.json. tools/fetch_editor_fonts.py는 고정된 공식 배포 경로만 읽는다. PNG ZIP에는 사용 글꼴의 OFL 원문을 함께 넣고 폰트 바이너리는 넣지 않음.
기존 저장본의 Noto Sans KR 설정은 그대로 읽으며, 신규 세 조합은 내려받은 공식 파일을 사용한다. 이전 실험용 프로필은 저장본 호환을 위해 내부에서 읽을 수 있지만 새 선택 목록에는 노출하지 않음.

## 편집 기능
- 초기 카드 구성·검수 갤러리·편집기에 카드별 한 줄 팁. 강제 템플릿이나 자동 배치 아님.
- 전체 폰트 미리보기 → 취소 또는 전체 카드 저장. 크기·위치·글 내용 유지, 선택 조합의 제목/본문 굵기만 적용. 취소는 위치·문구 변경을 유지하면서 폰트와 이전 굵기만 복원.
- 사진 중심 / 글·사진 분리 / 텍스트 중심. 현재 배치 유지가 기본. 미리보기·취소·현재 카드 적용 후 개별 저장. 분리형은 사진을 하단 영역에 클리핑, 텍스트형은 사진을 숨기되 원본 보존.
- 사진 표시/숨김과 단색 바탕색 직접 편집. 기존 배치·원본·본문2,054자·태그8개를 자동으로 덮어쓰지 않음.
- POST /api/save_layouts는10장 모두 검증 후 새 자산·SQLite 상태 저장. 한 장이라도 글이 넘치거나 잘못되면 기존 저장본 보존, 해당 카드 번호 안내. 개별 저장 API는 이전 편집기와 호환.

## 2026-10-26 즉시 적용과 광학 크기 보정
옵션명은 세리프 / 산세리프 / 손글씨로 줄였다. 선택 즉시 전체 카드에 서체와 크기·제목/본문 간격을 적용하고 저장은 별도로 한다. 기존 미리보기 버튼은 숨김 처리했다. 카드 유형은 현재 카드에 즉시 적용하며 되돌리기가 가능하다.
세리프는 기준 제목×1.06·본문×1.08, 산세리프는 각각×1.00, 손글씨는 제목×1.25·본문×1.14로 시작한다. 최소 간격은 각각80/72/88px이다. 실제 줄바꿈 높이에 따라 본문을 재배치하고 남은 영역이 부족하면 크기를 줄인다. 분리형은 사진 시작 지점을 기준으로 글 영역을 맞춘다. 이 수치는 앱의 조정 기준이며 폰트 제작자의 권장 수치가 아니다.
기준 배치 font_bases를 별도로 저장해 스타일을 반복 선택하거나 저장·재접속해도 배율이 누적되지 않는다. 수동 수정 좌표/크기는 다음 조정의 기준으로 반영한다. 사진 위치와 원문은 유지한다. 자동 조정 후 눈으로 검수하고 개별 미세 조정이 필요하다.
분리된8772 DB에서 선택 즉시 반영, 94→손글씨118→세리프100→손글씨118, 전체 저장·재접속 후100/118 복원, 텍스트형 즉시 적용을 실제 브라우저로 검증했다. 자동검사15개 통과. 운영 DB의 저장 배치는 바꾸지 않았다. 위의 미리보기 버튼/크기 고정 설명은 이전 버전 기록이다.

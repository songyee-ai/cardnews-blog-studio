# 멍글 제작실 - 최종 PRD

작성 기준: 2026-10-26. 공개 검색어를 소재로 강아지 정보글과 카드뉴스를 만들고, 사용자가 검수·수정한 뒤 네이버에 직접 등록한다.

## 문제와 결과
소재 찾기, 근거 조사, 원고·이미지 제작을 따로 반복하는 불편을 선택·검수·저장 흐름으로 연결한다. 결과는 제목, 본문, 해시태그, 카드7장·보조3장, 삽입 순서와 근거 목록이다.

## 입력과 판단
공개 반려동물 키워드 목록, 데이터랩 비교 링크 또는 사용자가 붙여 넣은 date/keyword/index 표, 글의 관점과 편집 조건을 사용한다. 없는 지표는 null이다. 한 시점 목록을 상승 추세나 내 블로그 유입 실적으로 해석하지 않는다. 현재 후보 제안은 키워드별 편집 규칙이며, 원문 조사·원고·이미지 초안은 AI 도구로 만든 뒤 앱에 가져왔다.

## 사람이 결정하는 지점
소재와 관점 → 제목·목차 → 카드 표현·서체·배치 → 최종 승인. 이미 정한 강아지 중심·직접 발행 방식은 반복 질문하지 않는다.

## 실제 구현
독립 Python HTTP 서버·SQLite, 공개 HTML 수집, DataLab 연결/표 입력, 조사·기획 표시, 원고 수정·글자 수·주의 표현 점검, 카드 요소 드래그·서체/유형·크기·배경 조정, 저장 이력·버전 충돌 방지, PNG/ZIP과 최종 승인.

## 정상 실행과 부족 자료
실제 공개 목록에서 말티푸 선택 → 자료5개 → 본문2054자·태그8개 → 원본 이미지10장 → 직접 편집 → 최종 승인.

자료 부족 실행: 날짜·지수 없이 검색어만 있는 표를 실제 브라우저에 넣었을 때 'date,keyword,index 열이 필요'하다는 안내를 띄우고, 검색 추이를 판단하지 않았으며, 기존 공개 자료를 그대로 보존했다. 처음에는 안내가 화면 밖에 표시돼 놓치기 쉬웠고, 안내 위치로 자동 이동하도록 고친 뒤 같은 입력으로 다시 확인했다(evidence/insufficient-trend-data.png). 잘못된 배치와 오래된 버전도 오류로 표시하며 기존 저장본을 보존한다. 데이터랩 오류 HTML을 수치 자료로 받지 않는다.

## 완료 기준과 현재 상태
2026-10-26 최종 승인, 산세리프 제목105px·본문50px·체크리스트55px. 직접 조정한 그림 위치·문구 유지, 체크 표시 출력 보완. PNG/ZIP 일치, 확장 자동 검사16개 통과. 실제 협찬·광고 관계가 없음을 직접 확인했다.

## 경계
앱 자체의 무인 원문 조사·원고 생성·이미지 API·네이버 발행은 미구현. 정상 사례의 AI 초안은 앱 밖의 AI 도구로 만들었다. 공개 데모는 공개 자료와 승인 결과를 복원하며, 재수집은 인터넷 상태에 영향을 받는다. 다른 사람과의 교차 검수와 실제 휴대폰 판독 시험은 수행하지 않았다.

# 선택 이유와 실패 개선

| 항목 | 선택 및 이유 |
|---|---|
| 확장 분야 | 강아지 블로그 소재·원고·이미지 제작의 반복 작업 |
| 트렌드 | Creator Advisor 로그인 대신 공개 키워드+DataLab 링크/표 입력. 실제 유입수와 구분 |
| 소재 | 말티푸 입문 가이드. 공개 목록 후보 중 정보형 글과 연결하기 좋은 키워드 |
| 발행 | 네이버에는 직접 등록. 검수 가능한 파일을 먼저 제작 |
| 이미지 | 처음 만든10장을 유지. 새 사진 재생성 대신 요소 편집 |
| 편집 | 전체 서체4종과 카드별 사진형/분리형/텍스트형. 선택 즉시 화면, 저장은 별도 |
| 기본과 산세리프 | 기본=Noto Sans KR 제목/본문. 산세리프=도현체 제목+Noto Sans KR 본문 |
| 가독성 | 산세리프 확대안으로 확정. 기준 배치 저장으로 반복 배율 누적 방지 |
| 원고 기준 | 2000~2500자·이미지10장은 편집 목표. 공식 노출 조건으로 주장하지 않음 |

## 실패 → 개선 → 재확인
1. 로그인 전 Creator Advisor 자료를 읽지 못함 → 공개 목록과DataLab로 대체 → 실제 검색어 기반 후보 표시.
2. DataLab 다운로드가 HTTP200 오류 HTML → 수치 파일 성공으로 처리하지 않음 → 링크와 사용자 정규화 표 입력으로 진행.
3. 편집기 이관 때 모든 카드가 사진형 → 텍스트형 등 유형 옵션과 한 줄 구성 팁 추가 →7번 텍스트형 검증.
4. 글꼴 선택이 무반응처럼 보임 → 글 없는8~10번 안내·서체 샘플·미리 읽기·완료 상태 추가 →10번 선택 후1번에서도 서체 반영 확인. 완전 무반응은 새 화면에서 재현되지 않았다고 구분.
5. 기본 옵션이 저장된 산세리프와 같아 보임 → 원래 Noto Sans KR 기본을 별도 선택지로 추가 → 기본94px/산세리프105px 제목 전환 확인.
6. 7번 카드에 넣은 체크 이모지가 PNG에서 깨짐 → 글꼴 추가 없이 체크 도형으로 출력 →3개 표시·ZIP 확인. 배치 JSON과 나머지9장 PNG 동일.

7. 검색어만 있는 표(자료 부족 입력)를 넣으면 부족 안내가 화면 밖에 표시돼 놓치기 쉬움 → 안내 위치로 자동 이동 → 같은 입력으로 안내와 기존 자료 보존을 다시 확인.

원본·이전 버전은 보존한다. 수정하면 현재 결과의 승인을 해제하고 새 버전을 검수한다.

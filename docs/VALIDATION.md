# 최종 검증

2026-10-26 원래 앱26개·확장16개 자동 검사 통과. PNG·ZIP·편집 JSON 일치, 체크 표시 보완 때 다른9개 PNG 바이트 동일. 잘못된 배치·중복 요청·오래된 버전 거부는 자동 검사로 확인. 실제 Claude 재호출·무인 생성API·네이버 게시·다른 사람과의 교차 검수는 미수행. 배포본 자체 실행 결과는 SUBMISSION_CHECK.json 참고.

## 정상 입력과 자료 부족 입력

| 실행 | 입력 | 기대 결과 | 실제 결과 | 수정 후 결과 | 확인 방식 |
|---|---|---|---|---|---|
| 정상 입력 | 공개 반려동물 목록(2026-10-24 기준 8개) | 관측한 검색어로 소재 후보 제안 | 소재4개 제안 → 말티푸 선택 → 자료5개 → 원고 공백 제외2054자·태그8개·이미지10장 → 직접 편집 → 원고v9 최종 승인 | 수정 불필요 | 실제 외부 HTTP·실제 브라우저 |
| 자료 부족 입력 | 날짜·지수 없이 검색어만 있는 표 | 추이를 판단하지 않고 부족한 열을 알림 | 'date,keyword,index 열이 필요해요' 안내, 기존 공개 자료 유지. 다만 안내가 화면 밖에 표시돼 놓치기 쉬움 | 안내 위치로 자동 이동하도록 고친 뒤 같은 입력으로 다시 확인 | 실제 브라우저, 의도적 부족 입력 (evidence/insufficient-trend-data.png) |
| 접근 제한 자료 | 데이터랩 다운로드 주소 직접 요청 | 실제 수치 파일인지 확인 | HTTP200이지만 내용은 접근 오류 HTML | 수치 자료로 받지 않고 공식 화면 링크 + 정규화 표 입력으로 구분 | 실제 비로그인 HTTP 요청 |
